# Phase v5.13.0 — 启动页 + 登录页重设计 + 自定义背景

**版本**: v5.13.0
**状态**: done（代码 + 静态验证完成；实机视觉效果待远端 CI 构建后用户确认）
**方向**: Flutter 客户端

## 背景

用户三项 Flutter 客户端深度改造诉求的第二项（第一项 v5.12.0 游客本地播放已完成）。改造前 `router.dart` 鉴权校验期间实际展示的是 `LoginScreen` 本身（从未有过真正的启动页），登录页纯文字表单无背景无品牌感，Logo 是 `Icons.music_note_rounded` 套色块。

## 目标

有真正的启动页（鉴权校验期间展示，无交互控件）；登录页有可识别的品牌标识与毛玻璃卡片视觉；Settings 可自定义登录页背景图片。

## 任务清单

- [x] 新增 `InoriMark`（`lib/src/shared/widgets/inori_mark.dart`）：`CustomPainter` 手绘带缺口的樱花花瓣剪影，替换登录页/启动页/桌面侧边栏三处的旧图标
- [x] 新增 `AppRoutes.splash` + `SplashScreen`；`router.dart` redirect 逻辑新增 splash 专属分支（避免鉴权已解析但仍停留在 splash 路由时无规则匹配导致卡死）
- [x] 新增 `AppBackground` + `backgroundProvider`：登录页/启动页背景层，图片复制进 App 存储（吸取 v5.12.3 的沙盒教训）
- [x] `login_screen.dart` 视觉重做：品牌标识浮在背景上 + 表单收进毛玻璃卡片（`BackdropFilter` + 72% 不透明度 + 24 圆角）
- [x] Settings → Appearance 新增「登录页背景」入口：选图/更换/恢复默认 + 透明度滑块（0.1–0.8）
- [x] 新增 `background_provider_test.dart`：`BackgroundSettings.copyWith` 与透明度夹取逻辑

## 非目标（相对最初规划的调整，理由见 requirement.md v5.13.0 条目）

- 登录页宽屏双栏布局——v5.12.2 已把登录/游客态窗口锁定为不可调整大小的 440×720，场景不可达，取消
- 背景层挂载到全局（而非仅登录/启动页）——避免变成对全部既有页面的重新蒙皮工作量，范围收窄到用户截图实际展示的场景
