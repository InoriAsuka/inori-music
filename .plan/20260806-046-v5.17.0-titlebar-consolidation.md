# Phase v5.17.0 — 标题栏整合优化

**版本**: v5.17.0
**状态**: done（代码 + 静态验证完成；实机走查待远端 CI 构建后用户确认）
**方向**: Flutter 客户端 · 对标开源/商业播放器布局改进第一阶段

## 背景

用户提供 4 份参考资料要求调研开源/商业播放器布局设计并改进（完整计划见 `/Users/inorihimea/.claude/plans/smooth-toasting-manatee.md`）。Spotube（纯 Flutter 跨平台，技术栈与本项目一致）参考价值最高：标题栏是否用系统样式做成用户偏好开关；拖拽区域+窗口按钮整合进每页 AppBar 而不是维护一条独立全局横条。v5.15.0/v5.15.1 的 `AppTitleBar` 正是"独立全局横条"模式，与 13 个页面各自的 AppBar 叠成两层桌面 chrome。

## 目标

去掉独立标题栏横条，整合进各页面 AppBar；标题栏样式做成可切换的用户偏好。

## 任务清单

- [x] 新增 `DesktopAppBar`：AppBar 的 drop-in 替代，桌面端用 `DragToMoveArea` 包裹整个 AppBar（含按钮）+ 追加窗口按钮，移动端/系统标题栏偏好开启时行为等同普通 AppBar
- [x] 机械迁移 13 个 `Scaffold(appBar: AppBar(...))` 页面为 `DesktopAppBar(...)`
- [x] `main.dart` 移除 `AppTitleBar` 的 Column 包裹；删除已废弃的 `app_title_bar.dart`/`app_title_bar_test.dart`
- [x] 新增"使用系统标题栏"设置项（`system_titlebar_provider.dart` + `DesktopIntegration.applyTitleBarPreference()` 改 static 支持立即生效）
- [x] 新增 `GateWindowChrome`：给登录页/启动页补最小化的拖拽+关闭入口（这两个页面原来完全没有桌面窗口操作手段）
- [x] 新增 `desktop_app_bar_test.dart`：4 例覆盖移动端/Windows/macOS/系统标题栏偏好四种分支
