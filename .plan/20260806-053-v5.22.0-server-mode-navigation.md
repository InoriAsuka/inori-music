## 实现中发现并修复的三个真实 bug（都是新写的单测抓出来的）

1. **侧栏选中高亮从来没有真正画出来过**：侧栏根节点是 `Container(color:)`，`ListTile` 的 `selectedTileColor` 和水波纹要画在最近的 `Material` 祖先上，中间夹一层 `ColoredBox` 会把两者一起吃掉（Flutter 自带断言直接报了这个）。改成 `Material(color:)`。这是改造前就存在的问题。
2. **侧栏品牌行溢出 20px**：`InoriMark` + `Text('Inori Music', titleMedium/w700)` 在 220px 侧栏的 188px 内容宽度里放不下。改造前就存在。加 `Expanded` + 省略号。
3. **闭包捕获循环计数器**：分组渲染时 `flatIndex` 是跨组累加的单个变量，每个 `ListTile` 的 `onTap` 闭包捕获的是变量本身而不是当时的值——所有行点下去都传最终值 6，`items[6]` 越界，点任何导航项都没反应。改为每行先 `final index = flatIndex;` 快照。
