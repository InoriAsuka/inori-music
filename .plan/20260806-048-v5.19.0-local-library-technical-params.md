# v5.19.0 — 本地曲库浏览增强 + 技术参数展示

对标开源/商业播放器布局改进第三阶段（第一阶段 v5.17.0 标题栏整合，第二阶段 v5.18.0 Fluent Design 材质，第四阶段 v5.20.0 歌词页重做）。详见 `/Users/inorihimea/.claude/plans/smooth-toasting-manatee.md` 的 Phase v5.19.0 章节。

## 目标

- 本地曲库列表加排序选项（艺术家/专辑/标题、最近导入、标题 A-Z、时长）。
- 把 `audio_metadata_reader` 已经解析但被丢弃的技术参数（采样率/码率/流派/音轨号/内嵌歌词）落库并展示。

## 完成的改动

- `lib/src/local_library/local_library_db.dart`：`LocalLibraryTrack` 新增 6 个可空字段；schema v1→v2 迁移（`onUpgrade` 执行 `ALTER TABLE ADD COLUMN`）；新增 `LocalLibrarySortOrder` 枚举与顶层纯函数 `localLibraryOrderByClause()`；`queryAll` 接受可选 `sort` 参数。
- `lib/src/local_library/local_library_notifier.dart`：新增 `localLibrarySortProvider`（`shared_preferences` 持久化）；`build()` 用 `ref.watch` 监听排序偏好；`_importOne` 从已有的 `meta` 对象读取新增字段并落库。
- `lib/src/local_library/local_library_screen.dart`：AppBar 新增排序入口（`_showSortSheet`，复用皮肤选择器的底部弹层范式）；`_LocalTrackTile` trailing 加 `_FormatBadge` 格式徽标。
- `lib/src/player/full_player_screen.dart`：本地曲目新增详情图标按钮，`_showLocalTrackDetails` 展示格式/采样率/码率/文件大小/流派。
- `test/local_library_db_test.dart`（新增，6 例）。

## 验证

- `flutter analyze --no-fatal-infos`：0 issues（1 条与本次改动无关的既有 info）。

## 非目标 / 已知缺口

- schema 迁移不会重新扫描已导入的旧记录——旧记录的新增字段永久为 `null`，UI 按"未知"处理，不强制重新导入。
- 服务端曲目（非本地曲库）不展示技术参数——服务端 `CatalogTrack` 本身没有码率/采样率字段，不在本次范围。
