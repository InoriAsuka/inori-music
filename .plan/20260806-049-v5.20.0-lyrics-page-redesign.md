# v5.20.0 — 歌词页深度重做

对标开源/商业播放器布局改进第四阶段，也是本批次（v5.17.0–v5.20.0）的收官 phase。详见 `/Users/inorihimea/.claude/plans/smooth-toasting-manatee.md` 的 Phase v5.20.0 章节。

## 目标

- 歌词背景从纯色换成专辑封面模糊+暗角。
- 本地曲目（`local:` 前缀）支持内嵌 LRC/纯文本歌词，不再一律显示"暂无歌词"。

## 完成的改动

- `lib/src/lyrics/lyrics_background.dart`（新增）：`LyricsBackground` + 私有 `_BlurredArtwork`，`Stack` 叠皮肤纯色兜底 + 模糊封面 + 固定强度渐变暗角。
- `lib/src/lyrics/local_lyrics_provider.dart`（新增）：`localLyricsProvider`（读 `LocalLibraryDb`）+ 顶层纯函数 `parseEmbeddedLyrics()`（LRC 时间戳优先，否则整体纯文本回退）。
- `lib/src/player/karaoke_screen.dart`：`Scaffold.body` 换成 `LyricsBackground` 打底；`trackId` 按本地/服务端分流到 `localLyricsProvider`/`lyricsProvider`。
- `lib/src/player/full_player_screen.dart`：`_LyricsPage` 拆成外层（套 `LyricsBackground`）+ `_LyricsBody`（原有 loading/empty/data 分支逻辑，改为分流两个 provider）；顶部 Karaoke 按钮的本地曲目禁用条件从"一律禁用"改为"无内嵌歌词才禁用"。
- `test/local_lyrics_provider_test.dart`（新增，4 例）。

## 验证

- `flutter analyze --no-fatal-infos`：0 issues（1 条与本次改动无关的既有 info）。
- `flutter test --no-pub`：163/163 通过（159 存量 + 4 新增）。

## 非目标

- 桌面歌词悬浮窗（独立置顶窗口）——需要 `desktop_multi_window` 完全不同的技术栈，体量对得上单独一个 phase，本次不做。
- 逐字动画渲染逻辑本身未改动（已是同类产品主流实现）。
