# v5.9.1 — 歌词全屏卡拉 OK 模式

**版本**: v5.9.1
**状态**: planned
**完成日期**: 待定

## 背景

v5.1.0 的增强 LRC 解析支持逐字级内联标签 `<mm:ss.xx>`，`LyricsPanel` 已有 word-level coloring。但缺少卡拉 OK 核心体验：
- 大字号全屏幕显示
- 逐字高亮动画（跟随音乐进度）
- ESC 键退出回到歌词面板
- 更视觉化的字体样式与颜色

本阶段补齐这一完整流程，复用既有逐字数据结构。

## 改动规模

Web 端约 3-4 个新文件 + 2 个现有文件修改。

## 实现范围

1. **`services/web/lib/karaoke/hooks.ts`** — 新 hook，管理 `isKaraokeActive`、`positionMs`、`activeWordIndex`，利用 requestAnimationFrame 60fps 驱动字级计算

2. **`services/web/components/player/KaraokePanel.tsx`** — 全屏卡拉 OK 组件：
   - 背景：半透明黑遮罩 + Sakura Dusk 主色调樱粉大字
   - 每行文字：通过 `KaraokeLine` 渲染，每个字为单独 span，根据位置决定是正常色还是高亮色
   - Escape 事件处理：关闭并恢复焦点到触发按钮
   - 动画过渡：入场淡出，ESC 时淡入

3. **`services/web/components/player/PlayerBar.tsx`** — 新增 `KaraokeControl` 入口按钮，与 LyricsPanel 互斥（打开卡拉 OK 则关闭歌词面板）

4. **`services/web/lib/karaoke/styles.css`** — 字体调整：Zen Maru Gothic / Poppins 大号标题，字间距和行高优化

5. **更新 `LyricsPanel.tsx`** — 增加 `onKaraokeOpen` callback 作为打开卡拉 OK 的触发器

## 验证

- Web `npm run type-check` 通过
- Web `npm run lint` 通过
- 真实测试歌曲：
  - 卡拉 OK 按钮激活后大屏显示字幕，逐字按时间高亮
  - ESC 键正确关闭，焦点恢复
  - 颜色对比度达标（樱粉文字 ≥4.5:1 对深色背景）

## 非目标

- 不新增歌词数据源（仅消费既有 LRC/SRT/词曲数据）
- 不支持歌词编辑/创作
- 不涉及歌词对齐调整功能（固定速度）
- 不支持多语言同步显示（单语先行）

- Rosettrism 歌词聚合服务接入（v6+）
- 自定义字速调节（当前固定音乐节奏跟随）
