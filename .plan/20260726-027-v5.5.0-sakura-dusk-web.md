# v5.5.0 — 樱花薄暮浅色主题（Web）

日期：2026-07-26
状态：已完成

## 背景

已部署到 unraid 的 Web 播放器功能可用，但视觉是典型的「AI 暗黑模板」：电紫 `#9b5cff`
+ 近黑 `#070711` + Orbitron 赛博字体 + 扫描线，通用感强、缺乏产品个性。需求为按二次元
ACG 特色重做色调与风格。

第一轮实现了深色版樱花薄暮（深夜靛底 + 樱粉/天青），但深色底本身仍被判定为「AI 味」，
遂改为**明亮日系 ACG**：奶油白画布 + 樱粉/晴空青，画面中不出现任何黑色或灰色大面积背景。

主题在四处有副本，全部源自同一套 "Neon Shrine" 体系。本阶段只改 Web + 共享包，
admin 与 Flutter 端分别由 v5.6.0 / v5.7.0 跟进。

## 色板（WCAG AA 实测，非估算）

三条硬约束，均由实测得出而非经验假设：

1. **浅色系强调色做实心按钮时，白字极易不达标** —— 初版樱粉 `#FF7BAC` 上的白字仅
   2.4:1；改用中间色 `#E8467F` 仍只有 3.7:1。最终主色定为 `#D42062`（白字 5.0:1）。
2. **`--color-primary` 不能直接当作压在 `--color-primary-dim` 上的文字色** —— 侧栏
   选中态是樱粉字压淡樱粉底，只有 4.2:1（此问题为浏览器实时 DOM 扫描发现，离线色板
   审计未覆盖）。新增 `--color-primary-on-dim: #BD1550`（5.2:1）专门解决。
3. **`--color-border` 系列达不到 3:1，只能做装饰性分隔线** —— 控件轮廓必须用
   `--color-border-strong: #B77A96`（3.4:1 on card）。

```
画布   void #FFF7F2(奶油) → surface #FFFFFF(卡片) → raised #FFF0F5(腮红) → overlay #FCE7EF
边框   border #F2D9E4（装饰）  border-strong #B77A96（控件轮廓）
主色   sakura  #D42062  hover #BD1550  soft #FF8FB8(仅装饰填充)  dim #FFE4EE  on-dim #BD1550
副色   sky     #0A7D94  soft #7FD6E6   dim #E0F5F9
点缀   gold    #9A5B00  soft #FFC978   dim #FFF1DC
语义   success #0B7A53  warning #9A5B00  danger #C81E2C  info #0A7D94
文字   text #3B2A3F(梅墨,13.2)  secondary #6B5570(6.7)  muted #7E6884(5.0)
```

字体：`Zen Maru Gothic`（日系圆黑，标题）+ `Poppins`（正文）+ `JetBrains Mono`（时间码）。
删除 Orbitron —— 它是原赛博感的主要来源。中文回退链含 `PingFang SC` / `Microsoft YaHei`。

## 实现范围

### 1. 主题层
- `services/web/app/globals.css` —— 重写 `@theme`，`color-scheme: light`；保留全部
  向后兼容别名（被 41 个文件引用）；圆角放大（md .75rem / lg 1rem / xl 1.25rem / 新增 2xl）；
  新增 `.card-soft` / `.card-float`（粉调阴影，不用灰黑）、`.aurora-veil`（三层径向渐变
  氛围底）、`.petal` 飘落动画、`.vinyl-spin`；删除 `.scanlines`。
- `packages/ui/src/styles/neon-shrine.css` → `sakura-dusk.css`，同步同一套 token，
  供 v5.6.0 admin 复用；`packages/ui/package.json` 的 `./styles` 导出路径同步。
- `packages/ui/src/components/NeonCard.tsx` —— 阴影写死的旧电紫 hex 改为 CSS 变量。
- `app/layout.tsx` —— `themeColor` 改 `#fff7f2`，`statusBarStyle` 由
  `black-translucent` 改 `default`（浅色状态栏）。

### 2. 首页 Bento 卡片化
`app/(app)/page.tsx` —— 4 个等大方块改不对称网格：Tracks 卡 2×2 主视觉（渐层底 +
超大图标水印），Playlists 卡横跨末行两列消除空缺；卡片 `hover:scale-[1.02]` 用
transform 避免 reflow；Recently Added 补上封面缩略图；列表项由 `<div onClick>` 改
`<button>`（原先键盘不可达）。

### 3. 播放器 / 侧栏精修
- `PlayerBar.tsx` —— 进度条抽出 `ProgressBar` 组件，支持 pointer 拖拽（原先仅点击跳转）、
  hover 增高、圆形手柄、樱粉渐变；播放键 40→44px 并加 `active:scale-95`；
  `ControlBtn` 40→44px 满足触摸目标标准。
- `Visualizer.tsx` —— canvas 渐变原本写死三个旧主题 hex，改为挂载时读 CSS 变量
  （每帧读会触发 style recalc，故只读一次）。
- `Sidebar.tsx` —— 选中态由整块实心改为左侧 3px 指示条 + 淡樱粉底 + `aria-current`。
- `Topbar.tsx` / `BottomNav.tsx` —— 跟随新 token，chrome 用 void 让其退到内容之后。
- `Artwork.tsx` —— 圆角 `rounded-xl`，无封面时改粉→青渐层占位（Web 端 artworkUrl
  目前无处赋值，占位是常态）。

### 4. ACG 氛围元素
- `components/layout/PetalDrift.tsx`（新增）—— 6 片 CSS-only 樱花，`translate3d` 驱动；
  `prefers-reduced-motion` 下整体 `display: none`（仅归零 duration 会让花瓣僵在半空）。
- `.aurora-veil` 挂在主内容区，纯 CSS 静态渐变。
- `FullscreenPlayer.tsx` —— 封面 canvas 取色驱动背景光晕，跨域污染时回退主题渐变；
  播放时封面极慢旋转。

### 5. 顺带修复的既有缺陷
- **`--color-primary-foreground` 从未定义** —— 被 8 个文件、10 处引用（全是实心按钮
  文字）。旧深色主题下靠继承浅色文字侥幸正常，浅色主题下会直接失效。补上定义。
- **`bg-opacity-10` / `ring-opacity-20` 在 Tailwind v4 已失效** —— 登录页与安全设置页
  的错误提示因此渲染成实心红底红字（几乎不可读）。改用 `danger-dim` 底 + 边框。
- 安全设置页 `bg-green-500` / `text-green-600` 绕过主题，改语义 token。
- 四处硬编码 `bg-black/50`、`bg-black/60` 遮罩改 `--color-scrim`（梅墨半透明）。

## 验证

- `tsc --noEmit` 0 错；biome lint 源码 96 文件 0 错；vitest 203 tests 全绿
- Playwright：6 passed。另 3 个播放相关用例失败（main-flow / gapless / user-playlists），
  已用 `git stash` 回退到改动前复跑确认**同样失败**——根因是本地种子数据的 media object
  指向不存在的音频文件，与主题改动无关。
- Chrome DevTools MCP 实机走查：375 / 1440 两档，登录页 → 首页 Bento → 曲目/专辑/艺人 →
  搜索 → 设置 → 队列抽屉；注入对比度脚本扫描 **7 个页面**的实时 DOM 文字/背景配对，
  修复后 **0 处不达标**（此扫描发现了离线审计漏掉的侧栏选中态问题）。
- reduced-motion：从 CSSOM 读取实际编译产物，确认 `.petal { display: none }` 与
  `.vinyl-spin { animation: none }` 生效。
