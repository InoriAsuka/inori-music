# v5.7.0 — 樱花薄暮浅色主题（Flutter 端对齐）

日期：2026-07-30
状态：completed

## 背景

v5.5.0（Web）/ v5.6.0（Admin）已确立「樱花薄暮」浅色 ACG 色板。
`services/mobile/lib/src/shared/theme/neon_shrine.dart` 仍是深色
Neon Shrine（`primaryViolet #9B5CFF` + `background #0D0D14`），需对齐。

## 改动规模（已实测统计）

不是改一个文件就完事——**22 个 Dart 文件**直接引用主题符号，共 **240 处**
`NeonShrineColors.*` 引用。重命名会全部波及：

| 符号 | 引用次数 |
|---|---|
| `onSurfaceVariant` | 73 |
| `error` | 26 |
| `primaryViolet` | 24 |
| `onSurface` | 23 |
| `outlineVariant` | 16 |
| `surfaceContainer` / `primaryVioletLight` / `onBackground` | 各 14 |
| 其余（surfaceVariant / primaryVioletDark / surface / outline / background / accentPink / playerBar / onError / accentCyan） | 46 |

## 实现范围

1. **`neon_shrine.dart` → `sakura_dusk.dart`**
   - `NeonShrineColors` → `SakuraDuskColors`，`buildNeonShrineTheme()` →
     `buildSakuraDuskTheme()`
   - `ColorScheme.dark` → **`ColorScheme.light`**（这是最容易漏的一步：仅改颜色值
     而不改 brightness，Material 组件的默认前景色推导仍按深色走，会出现深底浅字残留）
   - `primaryViolet*` 这批命名已语义错误（值将变为樱粉），建议一并改为
     `sakuraPink` / `sakuraPinkLight` / `sakuraPinkDark`。240 处引用建议用
     `sed` 批量替换后再 `flutter analyze` 兜底。

2. **色板映射**（值与 `packages/ui/src/styles/sakura-dusk.css` 保持一致）
   ```
   background      #FFF7F2   surface       #FFFFFF
   surfaceVariant  #FFF0F5   surfaceContainer #FCE7EF
   sakuraPink      #D42062   Light #FF8FB8   Dark #BD1550
   accentCyan      #0A7D94   accentPink    #FF8FB8
   onBackground / onSurface  #3B2A3F        onSurfaceVariant #6B5570
   outline #B77A96           outlineVariant #F2D9E4
   error   #C81E2C           onError       #FFFFFF
   playerBar #FFF0F5
   ```
   - `onPrimary` 必须是**白色**（`#D42062` 上白字 5.0:1）；若沿用旧的
     `Colors.white` 恰好正确，但 `onSecondary`（旧值 `#001A26` 深色）需改为白色。
   - `miniPlayerShadow` 旧值 `0x80000000`（50% 纯黑）在浅色底上会显脏，
     改为梅墨半透明 `0x263B2A3F`。

3. **`prefers-reduced-motion` 对应处理** —— Flutter 端需读
   `MediaQuery.disableAnimationsOf(context)`，Web 的 CSS media query 不适用。
   若 Flutter 端目前无花瓣/旋转动画，此项可跳过（需先确认）。

4. **状态栏 / 系统 UI** —— 浅色主题下 `SystemUiOverlayStyle` 需改为
   `dark` 图标（深色图标配浅色背景），否则状态栏图标会不可见。

## 验证

- `flutter analyze --no-fatal-infos` → 0 issues
  （注意：`flutter.yml` 与 `build.yml` 都必须带 `--no-fatal-infos`，
  这个 flag 不一致曾在 v4.8.2 造成 CI 红）
- `flutter test --no-pub` → 全绿
- **必须在模拟器/真机实机走查**，无法像 Web 那样用 DevTools MCP 注入脚本验证：
  登录 → 曲库各页 → 播放 → 全屏播放器 → 歌词 → 设置，逐屏确认无深底浅字残留。
- 对比度需**手工核对**关键配对（列表标题、次要文字、徽章、错误提示），
  Web 端的实测结论可直接复用：`#3B2A3F`/白 13.2:1、`#6B5570`/白 6.7:1、
  白/`#D42062` 5.0:1 均达 AA。
- 重点检查 `onSurfaceVariant`（73 处引用，覆盖面最大）在各类背景上的可读性。
