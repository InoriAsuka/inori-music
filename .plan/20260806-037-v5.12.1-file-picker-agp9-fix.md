# Phase v5.12.1 — file_picker / AGP 9 兼容性修复

**版本**: v5.12.1
**状态**: done（代码 + 静态验证完成；Android/Windows/macOS 实机构建待远端 CI 确认）
**方向**: Flutter 客户端

## 背景

推送 v5.12.0 后，远端 CI 的 `Flutter CI`（`Build APK` job）与 `Build`（`Flutter mobile checks` job）均失败，`Docker` 通过。两处失败是同一根因：`android/app/src/main/java/io/flutter/plugins/GeneratedPluginRegistrant.java:34: error: cannot find symbol class FilePickerPlugin`。

`file_picker` 10.3.9/11.0.0 起在自身 Android `build.gradle` 里应用了已弃用的 `kotlin-android` 插件，与本仓库固定的 AGP 9.0.1（内置 Kotlin 支持）冲突，导致其 Kotlin 源码未被正确编入构建图。上游已知问题（`miguelpruivo/flutter_file_picker` issue #1973/#1942/#1952），确认降级到 `10.3.10` 可规避。

## 目标

Android APK 构建恢复绿灯，不影响已完成的 guest 本地播放功能。

## 任务清单

- [x] `pubspec.yaml`：`file_picker` 从 `^11.0.3` 改为精确锁定 `10.3.10`，加注释说明原因和未来升级前的确认步骤
- [x] `local_library_notifier.dart`：`FilePicker.pickFiles/getDirectoryPath`（11.x 静态方法）改回 `FilePicker.platform.pickFiles/getDirectoryPath`（10.x 实例访问，真实的跨大版本 API 变更）
- [x] 本地 `flutter analyze` + `flutter test` 回归确认

## 非目标

- 不追加新功能，纯粹修复上一版本引入的 CI 缺陷

## 验证记录

`flutter analyze --no-fatal-infos` 0 issues；`flutter test --no-pub` 113/113 通过。本地无 Android SDK 无法直接复现/验证 Gradle 构建，Android/Windows/macOS 实际构建结果待本次推送后远端 CI 确认。
