# Phase v5.12.0 — Flutter 游客本地播放模式

**版本**: v5.12.0
**状态**: done（代码 + 静态验证完成；实机走查待远端 CI 构建产出后由用户验证）
**方向**: Flutter 客户端

## 背景

用户提出三项 Flutter 客户端深度体验改造需求，本 phase 是第一项：客户端允许不登录、以游客身份作为纯本地播放器使用。改造前客户端 100% 依赖服务端账号——`AuthStatus` 只有 `loading/authenticated/unauthenticated`，`router.dart` 的 `redirect` 对任何非 `authenticated` 状态一律导回 `/login`；全仓库没有本地文件播放路径，既有"离线"功能是"已登录状态下缓存服务端曲目"，与"不登录也能用的本地播放器"是两个不同的概念。

## 目标

游客无需账号即可导入设备上的本地音频文件并播放，复用现有 mini player / full player / 队列 UI，不新增一套平行的播放器实现。

## 非目标

- 皮肤/背景/桌面窗体——分属 v5.13.0–v5.15.0
